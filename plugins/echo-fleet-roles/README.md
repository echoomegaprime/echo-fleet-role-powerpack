# echo-fleet-roles (canonical)

Sole Codex role-power skills plugin for ECHO fleet doctrine.

- Invoke: `echo-fleet-roles:echo-judge-power` (and other `echo-*-power` skills)
- Includes `echo-role-switching` and `echo-fleet-base`
- Do **not** also enable `echo-fleet-role-powerpack@echoomegaprime` as a skills plugin

This package lives in the powerpack repo so the MCP connector and the skills source stay versioned together, but only **one** skills plugin must be enabled.
